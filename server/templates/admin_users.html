Telegram setup
  1. In Telegram, message @BotFather → /newbot, and copy the token into server/config.py (TELEGRAM_BOT_TOKEN). Restart the server.
  2. The emergency contact opens your bot in Telegram and presses Start (or sends any message).
  3. Click Edit on a user below, then Find chat ID, and pick that person. Use Test alert to check.
